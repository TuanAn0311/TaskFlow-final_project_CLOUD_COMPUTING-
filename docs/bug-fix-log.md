## Known findings not fixed

- Mobile task/team pagination is missing; both views cap responses at 100 records.
- Mobile dependency tree still reports 22 audit advisories. npm's automatic remediation suggestions require major Expo/React Native downgrades; no force fix was run.
- Web JWT storage in `localStorage` remains vulnerable to token theft if an XSS occurs.
- Render Free PostgreSQL is temporary and has no backups.
- Integration tests remain blocked until a dedicated disposable `TEST_DATABASE_URL` is configured and verified by the owner.
- The emulator booted, but Expo Go failed to download a remote update; Android login/task flows, Render deployment, backup/restore, and release signing remain unverified.
- An integration command was inadvertently started before the DB guard was added and stopped after roughly 30 seconds without a Jest result. Whether it wrote or cleaned test records is unknown; the user was notified to inspect the DB. No further DB access or cleanup was performed.
